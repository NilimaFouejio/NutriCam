# Rapport d'anomalies des documents de référence

Aucune valeur du document n'a été corrigée : les valeurs source sont conservées dans `V5__donnees_reference_plan.sql` et dans `src/test/resources/reference/`. Les anomalies A-01, A-03 et A-04 ont un test qui les documente (`CalculEnergetiqueTest`, `GenerateurProgrammeTest`).

Contrôles faits par script sur les 21 tableaux (7 jours × 3 profils), 63 repas : énergie de chaque ligne (quantité × densité), sous-totaux g et kcal par repas, cibles de repas (25/55/20 %), totaux journaliers.
**Résultat : 0 erreur de ligne ni de sous-total de repas.** Les anomalies portent sur les totaux journaliers et sur les fiches de calcul.
